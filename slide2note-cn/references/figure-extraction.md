# 抠图守则（自带 scripts/safe_crop.py，无外部技能依赖）

本技能自带抠图脚本 `scripts/safe_crop.py`（路径相对本技能目录）。依赖三个 Python 包：`pymupdf`、`Pillow`、`numpy`（缺了先 `pip install`）。

核心目标只有一句话：**完整优先于紧裁**。多留白边可以接受，裁掉标签、箭头、图例、坐标轴、公式、注释不可接受。

## 方法论（先想清楚，再动剪刀）

1. **别把第一个检测到的框直接当最终裁剪框**，必须经过验证。
2. 图本身是**嵌入位图**且完整时，优先直接提取该图，不要渲染裁剪。
3. 图由**矢量图形 + 文字标签 + 公式 + 图例**拼成时（幻灯片课件几乎都是），按"整页高分辨率渲染 → 裁渲染图"处理。
4. 用图注（Figure / Fig. / 图 / Diagram）或邻近说明文字做**定位锚点**。
5. 完整的图 = 主图形区 ∪ 坐标轴与刻度 ∪ 图例 ∪ 箭头 ∪ 标注气泡 ∪ 所属公式 ∪ 子图标签 (a)(b) ∪（需要保留时）图注本身。
6. 并集 bbox 之外再加**安全 padding**。

## safe_crop.py 用法

bbox 用 PyMuPDF 页面坐标（pt，72 pt/英寸）：

```bash
python3 <技能目录>/scripts/safe_crop.py input.pdf \
  --page 12 \
  --bbox 100 180 500 620 \
  --dpi 350 \
  --padding 0.06 \
  --output figure.png
```

- `--dpi` 最终输出分辨率，讲义插图用 **350**。
- `--padding` 分数式四周扩框，默认 0.06；实际扩量 = max(4pt, 尺寸×分数)。
- **退出码 0 正常；1 = 边缘接触警告**（某条边 16px 条带内深色像素占比 ≥8%，很可能截断了内容，stderr 会列出可疑边）；2 = 参数/文件错误。
- 脚本会把最终 bbox 和四边接触分数打印出来，据此判断要不要回炉。

## 踩坑守则（实测换来，裁剪前通读）

### 坐标永远精确查询，不要目测

目测低分辨率渲染图估算 bbox 非常不可靠——经常混入标题色带/相邻正文，或裁掉图内标签。坐标一律用 pymupdf 查：

```python
import pymupdf
page = doc[page_no]
words = page.get_text('words')     # 每个词的精确 bbox
drawings = page.get_drawings()     # 色带、线条、矩形等矢量元素
```

### expand_rect 反向补偿

safe_crop.py 的 padding 会把框向四周各扩 `max(4pt, 尺寸的 1%)`。估算边界时必须把这 ~4pt 算进去反向补偿，否则扩完就蹭到相邻元素。例：标题色带底边 y=90、图顶元素 y=93——93 扩完变 89，仍然蹭到色带，bbox 必须先上移。

### 文字反锯齿溢出（descender）

word bbox 不含反锯齿溢出：

- 字形下伸部（g/y/p/q）可比 words 报告的 y1 再低 2–4 pt；
- 同一行上方文字的 descender 会伸进下一行区域——定顶边时要么再压 4–6 pt，要么裁完后用 PIL 白化残留；
- 底边一律多留 ≥8 pt。

### 标题色带：逐页查，别套统一值

幻灯片课件普遍有标题色带，且**高度不一定每页一致**（实证：某课件多数页色带底边 y=90，个别页到 y=98.9）。每页用 `page.get_drawings()` 查色带矩形实际底边再定 bbox。

### 页脚页码：先查一次，整本通用

页码通常固定在页面右下角。做法：任取一页用 `get_text('words')` 找到页码词的 bbox（实证：某课件固定在 (663,497)-(677,513)），裁剪区与该角相交时，裁完用 PIL 把该角白化，否则成品图带着页码。

### 残字清理：优先 PIL 白化，别反复调 bbox

课件自带的孤立字符（项目符号、上一行 descender、stray 字母）混进裁剪区时，先查 word 坐标确认残字与正文内容错开，再按精确 bbox 用 PIL 白化——比反复调裁剪框快得多：

```python
from PIL import Image, ImageDraw
im = Image.open(path); d = ImageDraw.Draw(im)
s = 350/72  # dpi 缩放
d.rectangle([x0*s, y0*s, x1*s, y1*s], fill='white')
im.save(path)
```

### 标签压在色带上：颜色键清除

图内标签压在标题色带上时，把色带一起裁进来，再按颜色键清除：把接近色带颜色的像素整批置白（色距阈值按实测调，如对 RGB(204,204,255) 的色带用 dist<60），可完整保留深色线条和文字。

## 校验流程

1. 批量裁剪用**清单循环**（bbox + 每图的白化坐标写在清单里），不要逐图手跑。
2. 裁完逐张 Read 目检：四边有无截断、有无混入色带/相邻正文/页脚、残字。
3. safe_crop 报的**边缘接触 warning 一律当真**——查了多半真有截断。
4. 交付前的整册视觉审查（见 SKILL.md 第 5 步）还会再抓一轮漏网之鱼，不要跳过。
