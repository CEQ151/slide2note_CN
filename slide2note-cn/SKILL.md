# slide2note-cn：课件 PDF → 中文 LaTeX 讲义 PDF

三条原则贯穿全程：**忠实课件**（逐页覆盖、不遗漏模块，补全必须显式标注）；**直接讲解**（不逐字复述幻灯片——用户曾因"逐节重述、冗长、不美观"退回成品，这是红线）；**排版精良**（公式全 LaTeX 化、语义彩盒、统一主题色，成品必须经逐页视觉审查）。

## 工作流程

### 第 1 步：定双根、通读课件、建图片台账

- **双根职责分离**：从课件 PDF 逐级向上找含 `.obsidian/` 的目录即 vault 根，课件所在的 vault 第一级子目录即**课程文件夹** `<课程>`。构建根 `<工作区>` = `<vault>/_slide2note/<课程名>/`，含 `tex/`、`images/`（下分 `chNN/`）、`render/`、`pages/`、`notes/` 五个子目录——一切中间产物（tex 源、切片、审查渲染、整页渲染、台账、草稿、一次性脚本）只落这里；交付根 = `<课程>/AI Notes/`，只平铺成品 PDF。课件不在 vault 内时回退：`<工作区>` = `<课件目录>/_slide2note/`、`<课程>` = 课件目录；用户另有指定交付位置时以用户为准。目录缺失先 `mkdir -p`。
- **首次忽略自检（防同步抢跑）**：首次创建 `_slide2note/` 前确认双重排除——`.obsidian/sync.json` 的 `excludedFiles` 含 `"_slide2note/"`、`.obsidian/app.json` 的 `userIgnoreFilters` 含 `"_slide2note/"`；缺哪项用 JSON 合并补写（保留其余键值），并请用户**完全退出并重启 Obsidian** 后再继续。忽略未确认生效前，禁止往工作区写入任何文件。
- 环境自检：`xelatex` 与 Python 的 `pymupdf`/`Pillow`/`numpy`；缺了先提示安装再动手。
- 用 Read 分段读完课件全部页面（每次 ≤20 页），记录总页数、模块划分与各模块页码范围。
- **全册图片台账**（落盘 `<工作区>/notes/ledger-tN.md`，禁止散落课程文件夹）：逐页登记每张图/图形元素，一张不漏——这是抠图、写作、审查三环节共同的"零漏图"契约，必须先于抠图完成：

  | 课件页 | 图片内容 | 类型 | 处置 |
  |---|---|---|---|
  | P7 | 三级流水线结构图 | 教学图 | 抠图 → `fig-03-07-pipeline-internal.png` |
  | P15 | 真值表（本质为表格） | 教学图 | 重排为 LaTeX 表 3.2 |
  | P8 | 猫猫头表情包 | 装饰图 | 豁免：整活图，与知识点无关 |

- **收录规则**：图分**教学图**（承载知识点的任何图形）与**装饰图**（表情包、梗图、logo 等与知识点无关的整活图）。教学图 100% 收录并逐一讲解——收录 = 抠图或 TikZ 重绘，本质为表格/公式的重排为 LaTeX；讲解 = 图注交代读法 + 正文讲解段落 + `\ref` 引用。装饰图可豁免，但豁免必须连同理由写进台账留痕，禁止默默丢弃；拿不准一律按教学图。纯文字幻灯片无台账条目。
- 抠图用自带 `scripts/safe_crop.py`，裁前先读 `references/figure-extraction.md`。
- **开工初检（工作区已存在时）**：`python "<技能目录>/scripts/cleanup.py" --organize "<工作区>"` 先 dry-run、确认后 `--apply`——被引用图的机械级乱命名（大小写、空格/下划线、`-v2` 等废稿后缀、缺补零）自动改名并同步改写 tex 引用，垃圾与重复图清除；报告列出的语义级违规（中文 slug、缺页码、游离 `images/` 根、未被引用的图）按台账逐条改名、改写引用、接线或判废。

### 第 2 步：抠图

- 台账即工作清单，逐条执行；插图输出 `<工作区>/images/chNN/`（NN=讲次两位数），命名 `fig-NN-页-slug.png`（图序号-课件页码-英文短名），最终 350 dpi。每张裁完立即 Read 目检；safe_crop.py 边缘接触 warning（退出码 1）一律当真、逐一排查。
- 禁止在源头降 dpi/降质省体积——体积由第 4 步编译后的硬门统一管控。
- **输出卫生**：裁剪永远写台账定名的最终文件名（同名覆盖，禁攒 `fig-xxx-v2` 废稿）；调 bbox 的低分辨率探查渲染放系统临时目录，禁落 `images/`；整页预渲染放 `<工作区>/pages/`，禁止在课程文件夹另起 `_courseware_pages*` 目录。

### 第 3 步：编写 LaTeX 讲义

- 位置 `<工作区>/tex/第N讲-标题.tex`；先读 `references/latex-template.md`，复制导言区与骨架填充，不从零发明。骨架七节顺序固定：
  1. 封面 titlepage：讲号 + 中英双语标题 + 信息盒（课程、学期、依据课件、绘图说明）+ TikZ 知识地图（模块节点与箭头拓扑）。
  2. 目录。
  3. 内容地图：三列表（模块 / 课件页 / 核心问题）。
  4. 专有名词中英对照：longtable 三列（英文 / 中文 / **大白话解释**），带续表表头。
  5. 正文：按课件页序分 `\subsection`，**标题必标课件页码**，如 `\subsection{细胞呼吸的三个阶段（P12--P13）}`。
  6. 章末小结：yaodbox 知识速查表（booktabs）+ sikaobox 课后自测（5 题左右，覆盖本讲全部考点）。
  7. 尾部来源声明：居中小字（依据课件名与页数、图片来源与 dpi、校验方式）。
- **分节写作（防尾部板块缩水）**：禁止一次性 Write 整册 tex。小讲次（模块 ≤3、预计 ≤800 行）主 agent 自己按节写，写完一节再写下一节；大讲次主 agent 转**编排者**按模块派 subagent 并行，写作期用 `main.tex` + `secN-*.tex`（`\input`）保持随时可编译，交付前合并回单文件（默认交付形态）。
- **编排者纪律**：通读课件、台账、抠图（可派专用 subagent）、**名词表定稿**、内容地图不外包。每个写作 brief 必含：① 本节覆盖的课件页码与模块边界 + 上节已讲内容（本节不得重复）；② 本节台账条目（图已抠好，含最终文件名）；③ 定稿名词表（不得另造术语）；④ 输出纪律——只返回 `\section` 起的正文 tex，**禁止任何导言区指令**（`\usepackage`/`\definecolor`/`\newtcolorbox`/`\newcommand`），只用主模板已定义的环境与宏，遵守每图必讲、小节标 P 页码、插图宽度分档、公式全 LaTeX 化；subagent 自己 Read 对应课件页原文，不靠转述。
- **衔接 pass（汇编后、编译前）**：通读全册 tex，修节间过渡生硬、相邻节重复讲解、术语口吻不一致。
- 配套作业卷按 `references/homework-sheet.md` 另做（独立 tex、独立 PDF）。

### 第 4 步：编译

```bash
cd "<工作区>/tex"
xelatex -interaction=nonstopmode -halt-on-error "第N讲-标题.tex"
xelatex -interaction=nonstopmode -halt-on-error "第N讲-标题.tex"   # 第二遍出目录与交叉引用
cp "第N讲-标题.pdf" "<课程>/AI Notes/"   # 成品平铺进交付根（同名覆盖旧版）
```

- **体积硬门（编译后立即执行，不可跳过）**：`python -c "import os; s=os.path.getsize('第N讲-标题.pdf'); print(f'{s/1048576:.2f} MB')"`。≤4.5MB 通过；>4.5MB 逐档压图降载，每档跑完重编译再查，禁跳档——档 1：`python "<技能目录>/scripts/shrink_images.py" "../images"`；档 2：加 `--downscale 2000`；档 3：加 `--downscale 1600`。**5MB 是绝对红线**（Obsidian 同步限制）：超限 PDF 禁止交付；三档压完仍超限时如实报告体积与权衡方案，严禁删图、删内容、砍页面凑体积。
- 硬门通过后**及时清理**：`python "<技能目录>/scripts/cleanup.py" --aux "<工作区>" --apply`（只删编译产物；编译失败时保留日志排查，不跑这步）。
- 非 macOS 环境调整 documentclass 的 `fontset`（Windows 用 `fontset=windows`，Linux 视发行版），见模板。

### 第 5 步：视觉审查（不可跳过）

- 用 pymupdf 把成品渲染为逐页 PNG 到 `<工作区>/render/`（脚本见模板末尾；pdftoppm 可用时也可替代），派视觉审查子 agent——环境里有 `pdf:visual-judge` 就用它，否则用任意能读图的通用 Agent——逐页检查：插图无截断残字、**图片宽度合适（无"整页仅一图无正文"版面）**、表格不溢出页边、公式无 Overfull 乱排、彩盒不跨页断裂、页眉页脚正常、压过的插图无肉眼可见劣化（模糊/色带/噪点）。
- **覆盖率核对（零漏图门槛）**：台账一并交审查 agent，逐页核对"课件图 → 讲义图/豁免理由"一一对应；漏图、漏讲解（只有图没有配文）、台账外多图，一律打回补齐后重审。
- 走过降载阶梯的讲义，交付前复核体积 ≤5MB；审查发现插图劣化，按模板兜底流程单独重抠该图。
- 对照课件复核数值、真值表、定理编号；按审查报告逐条修正、重编译重渲染，直到全部页面通过。

### 第 6 步：清理收尾与交付

- 审查与体积全过后：`python "<技能目录>/scripts/cleanup.py" "<工作区>"` dry-run 看清单，确认后 `--apply`——删编译产物、`render/`、`pages/`、脚手架、孤儿图；只动工作区，永不触碰交付根。
- 汇报：PDF 路径、页数、体积（X.XX MB，须 ≤5MB）、插图情况（课件图总数 / 收录讲解数 / 豁免数及理由，对齐台账）、审查结论、页码对应关系、清理与整理结果。
- tex 源码与插图路径（均在 `<工作区>` 下）一并告知，方便用户改版。**交付断言**：`python "<技能目录>/scripts/cleanup.py" --check "<课程文件夹>"` 验证 `AI Notes/` 只有平铺 PDF、课程文件夹无散落 AI 产物，最终目录树（交付根 + 工作区）随报告展示。

## 排版硬规则（红线）

- **输出地界**：课程文件夹内禁止写入任何非 PDF 文件——tex、切片、渲染、台账、草稿、脚本一律只落 `<工作区>`；`AI Notes/` 纯 PDF、禁子目录；工作区保持同步排除（见第 1 步自检），交付前复核。
- **公式全 LaTeX**（`$...$` / `\[...\]` / `align*`），图注和表格里也不许 Unicode 上下标（写 `$A'$` 不写 A′，写 `$2^N$` 不写 2ⁿ）；禁止 verbatim/lstlisting 包裹公式算式。
- **不逐字重述课件**：禁"页面内容"式复述引用块，每小节直接讲清"是什么、为什么、怎么用"。
- 表格用 booktabs 三线表、表头齐全、列数一致；长表 longtable 带续表头。
- **忠实标注**：补全课件留白标"解答/按方程求得"；课件之外的扩展标"补充"。
- **交付 PDF ≤5MB**（作业卷同限）：超限只许压图降载（第 4 步阶梯），严禁删图、删内容、砍页面凑体积。
- hyperref 最后加载；图一律 `\graphicspath{{../images/}}` + 相对路径引用。

## 语义彩盒体系（定义见模板文件）

| 盒子 | 颜色 | 用途 |
|---|---|---|
| dinglibox 定义 | 蓝 | 概念、术语的正式定义 |
| yaodbox 核心要点 | 绿 | 结论、速查清单、知识汇总 |
| litibox 例题 | 绿 | 完整解答的例题 |
| sikaobox 思考与讨论 | 橙 | 课件思考题、课后自测 |
| yuanbox 课件原图 | 灰框白底 | 课件抠图，与重绘图成对出现 |
| ansbox 参考答案 | 绿（作业卷用） | 作业题参考解答 |

## 图注与插图

- **每图必讲**：图注小字、自动编号"图 N"，内容是解释原理与读法并注明课件页码（如"课件第 8 页原图"），不是复述画面元素；正文至少一段讲解 + `\ref` 引用。只贴图不讲解视为未完成收录。
- **每张 `\includegraphics` 必须显式给宽度**，按信息密度缩放——350 dpi 缩小不会糊，放心缩；禁止不缩放塞入导致整页只有一张图。分档：小图（单个符号、简单小电路）0.3–0.5\linewidth，优先 `wrapfig` 环绕或 minipage 并排；中图（结构图、流程图、单张电路图）0.5–0.75；大图（多子图、密集标注）0.85–\linewidth；仅原图极复杂、缩小不可读才接近满页，且同页或次页必须紧跟讲解文字。
- 相关联的图（详图 + 简化符号、正误对比）minipage 并排、各设宽度；双栏并排优先 `[htbp]` + minipage，避免 figure 互相挤位。

## 版式（默认单栏，实现片段见模板）

| 版式 | 适用 | 实现 |
|---|---|---|
| 单栏（默认） | 公式多、宽表多、图大 | 现有模板即单栏 |
| 双栏 | 文字密集、图小而多、省纸 | 局部 `multicols`；整册在目录后 `\twocolumn` |
| 文字环绕 | ≤半栏小图配长段文字 | `wrapfigure` |

- 用户点名要双栏/紧凑，或某几节明显"小图 + 长文字"时才启用对应版式，不为花哨牺牲公式与表格的稳定。
- 宽元素禁忌：内容地图 tabularx、longtable、跨栏大图不进 `multicols`；整册双栏用 `figure*`/`table*` 跨栏。
- `wrapfigure` 三纪律：环境放在要环绕的段落之前、宽度 ≤0.5\textwidth、别紧贴章节标题或页面最后几行。

## 参考文件

- `references/latex-template.md` — 完整导言区（配色/标题样式/彩盒/页眉页脚 + 可选领域绘图宏）+ 骨架 + 片段 + 编译交付/体积/清理制度，写 tex 前先读。
- `references/figure-extraction.md` — 抠图方法论与脚本用法：精确坐标、padding 反向补偿、残字白化、色带处理。
- `references/homework-sheet.md` — 作业卷结构与模板（仅用户要求时使用）。
- `scripts/safe_crop.py` — 高分辨率渲染裁剪（pymupdf/Pillow/numpy）。
- `scripts/shrink_images.py` — PNG 批量压图（量化 + 可选降采样），超 5MB 降载阶梯用。
- `scripts/cleanup.py` — 工作区卫生脚本，dry-run 默认：默认模式删编译产物/审查渲染/整页渲染/脚手架/孤儿图；`--aux` 编译成功后及时清编译产物；`--organize` 开工初检命名整理（机械级自动修 + 改写引用，语义级报告由 agent 按台账处理）；`--check <课程文件夹>` 交付纯净断言。用法见 latex-template.md。
- `scripts/migrate_vault.py` — 存量库一次性整理：旧产物迁工作区、成品平铺 `AI Notes/`、灰色归档 `_legacy/`、改写旧链接；默认 dry-run。仅用户要求整理存量时用。

## 输出语言

讲义正文、图注、表格全中文，专有名词保留英文并首次出现给中文译名（名词表兜底）；tex 注释可中文。
