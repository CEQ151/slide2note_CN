# slide2note-cn：课件 PDF → 中文 LaTeX 讲义 PDF

把一份课件幻灯片 PDF 变成一份可复习、可打印的中文讲义 PDF。三条核心原则贯穿始终：

1. **忠实课件**：逐页覆盖、不遗漏模块；任何补全或课外扩展都必须显式标注。
2. **直接讲解**：不逐字复述幻灯片，用自己的讲解消化内容。用户曾因"逐节重述课件、冗长、不美观"退回过成品，这是红线。
3. **排版精良**：公式全部 LaTeX 化、语义化彩盒、统一主题色，成品必须经过逐页视觉审查。

## 工作流程

### 第 1 步：确定输出位置并通读课件

- **先定输出根目录**：默认用课件 PDF 所在目录下的 `AI Notes/`（内含 `tex/`、`pdf/`、`images/` 三个子目录）；若用户已有自己的笔记目录或指定了位置，以用户为准。目录不存在时先 `mkdir -p`，下文路径均相对该根目录。
- 环境自检：`xelatex` 可用（TeX 发行版）、Python 有 `pymupdf`/`Pillow`/`numpy`（抠图脚本依赖）；缺了先提示安装再动手。
- 用 Read 分段读完课件 PDF 全部页面（每次不超过 20 页），记下：总页数、模块划分与各模块页码范围。
- **建立全册图片台账**：逐页登记课件里每一张图/图形元素，一张不漏。这是后续抠图、写作、审查三环节共同的"零漏图"契约，必须先于抠图完成：

  | 课件页 | 图片内容 | 类型 | 处置 |
  |---|---|---|---|
  | P7 | 三级流水线结构图 | 教学图 | 抠图 → `fig-03-07-pipeline-internal.png` |
  | P12 | 数据通路总览 | 教学图 | TikZ 重绘 + yuanbox 原图对照 |
  | P15 | 真值表（本质为表格） | 教学图 | 重排为 LaTeX 表 3.2 |
  | P8 | 猫猫头表情包 | 装饰图 | 豁免：整活图，与知识点无关 |

- **收录规则**：类型只有两种——**教学图**（承载知识点的任何图形：类比示意、内部结构、带标注图表、应用实例等）与**装饰图**（表情包、梗图、纯色彩装饰、logo 等与知识点无关的整活图）。
  - 教学图 **100% 收录并逐一讲解**：收录 = 以图的形式进讲义（抠图或 TikZ 重绘），或对本质为表格/公式的元素重排为 LaTeX（在处置列注明）；讲解 = 图注交代读法 + 正文有对应讲解段落并用 `\ref` 引用。
  - 装饰图可豁免，但豁免必须连同理由写进台账留痕，**禁止默默丢弃**；拿不准算不算教学图时，一律按教学图收录。
- 纯文字型幻灯片（无任何图形元素）不涉及台账条目，内容直接用排版文字与公式表达。
- 需要抠图时使用本技能自带的 `scripts/safe_crop.py`；裁剪前先读 `references/figure-extraction.md`（方法论 + 实测踩坑守则 + 脚本用法）。

### 第 2 步：抠图

- 按第 1 步的台账逐条执行：处置列为"抠图/重绘"的教学图全部完成，台账就是工作清单。
- 插图输出到 `images/chNN/`（chNN 为讲次两位数，如 ch03），命名 `fig-NN-页-slug.png`：NN 是图序号、页是课件页码、slug 是英文短名，如 `fig-03-07-cell-membrane-transport.png`。
- 最终裁剪 350 dpi；每张裁完立即 Read 目检；safe_crop.py 报的边缘接触 warning（退出码 1）一律当真、逐一排查。

### 第 3 步：编写 LaTeX 讲义

- 位置：`AI Notes/tex/第N讲-标题.tex`。完整导言区与骨架见 `references/latex-template.md`，直接复制后填充，不要从零发明模板。
- 文档骨架（各节顺序固定）：

  1. **封面 titlepage**：讲号 + 中英双语标题 + 信息盒（课程、学期、依据课件、绘图说明）+ TikZ 知识地图（模块节点与箭头拓扑）。
  2. **目录**。
  3. **本讲内容地图**：三列表格（模块 / 课件页 / 核心问题），让读者 30 秒看懂全讲脉络。
  4. **专有名词中英文对照表**：longtable 三列（英文 / 中文翻译 / **大白话解释**），带续表表头。
  5. **正文讲解**：按课件页序分 `\subsection`，**标题必须标注课件页码**，如 `\subsection{细胞呼吸的三个阶段（P12--P13）}`。
  6. **章末小结**：知识清单速查表（yaodbox 内 booktabs 表）+ 课后自测（sikaobox，5 题左右、覆盖本讲全部考点）。
  7. **尾部来源声明**：居中小字，注明依据课件名与页数、图片来源与 dpi、校验方式。

- 默认交付**单文件** tex；课件特别长时写作期可拆 `secN-*.tex` 用 main.tex `\input`，但交付前合并回单文件。
- 如用户还要配套作业卷，按 `references/homework-sheet.md` 另做一份（独立 tex、独立 PDF）。

### 第 4 步：编译

```bash
cd "AI Notes/tex"
xelatex -interaction=nonstopmode -halt-on-error "第N讲-标题.tex"
xelatex -interaction=nonstopmode -halt-on-error "第N讲-标题.tex"   # 第二遍生成目录与交叉引用
```

- 编译产物（aux/log/toc）留原地，最终 PDF 拷贝到 `AI Notes/pdf/`。
- 非 macOS 环境记得调整 documentclass 的 `fontset` 选项（Windows 用 `fontset=windows`，Linux 视发行版），详见模板文件。

### 第 5 步：视觉审查（不可跳过）

- 用 pymupdf 把成品 PDF 渲染为逐页 PNG（脚本见 `references/latex-template.md` 末尾；pdftoppm 可用时也可替代），然后派发视觉审查子 agent——环境里有 `pdf:visual-judge` 就用它，否则用任意能读图的通用 Agent——在任务描述里附上检查清单，逐页检查：插图无截断无残字、**图片宽度合适（无"整页仅一图无正文"的版面）**、表格不溢出页边、公式无 Overfull 乱排、彩盒不跨页断裂、页眉页脚正常。
- **覆盖率核对（零漏图门槛）**：把第 1 步的图片台账一并交给审查子 agent，逐页核对"课件图 → 讲义图/豁免理由"一一对应；发现漏图、漏讲解（只有图没有配文）、或台账外多出的图，一律打回补齐后重审。
- 对照课件 PDF 复核讲义中的数值、真值表、定理编号。
- 按审查报告逐条修正，重编译重渲染，直到全部页面通过才算完成。

### 第 6 步：交付

- 汇报：PDF 路径、页数、插图情况（课件图片总数 / 收录并讲解数 / 豁免数及理由，数字对齐台账）、审查结论、与课件的页码对应关系。
- tex 源码与插图路径一并告知，方便用户后续改版。

## 排版硬规则（红线）

- **公式全部用 LaTeX**（`$...$` / `\[...\]` / `align*`），图注和表格里也**不许出现 Unicode 上下标**（写 $A'$ 不写 A′，写 $2^N$ 不写 2ⁿ）。
- **禁止用代码框**（verbatim/lstlisting）包裹公式或算式。
- **不逐字重述课件**：禁止"页面内容"式的复述引用块，每个小节直接讲解——讲清楚"是什么、为什么、怎么用"，而不是翻译幻灯片。
- **表格规范**：booktabs 三线表、表头齐全、列数一致；长表用 longtable 带续表头。
- **忠实标注**：课件留白的表补答案时标"解答/按方程求得"；课件之外的扩展内容标"补充"。
- hyperref 最后加载；图一律 `\graphicspath{{../images/}}` + 相对路径引用。

## 语义彩盒体系

用 tcolorbox 定义一套颜色语义固定的盒子，全文贯彻（定义见模板文件）：

| 盒子 | 颜色 | 用途 |
|---|---|---|
| dinglibox 定义 | 蓝 | 概念、术语的正式定义 |
| yaodbox 核心要点 | 绿 | 结论、速查清单、知识汇总 |
| litibox 例题 | 绿 | 完整解答的例题 |
| sikaobox 思考与讨论 | 橙 | 课件上的思考题、课后自测 |
| yuanbox 课件原图 | 灰框白底 | 专放课件抠图，与重绘图成对出现 |
| ansbox 参考答案 | 绿（作业卷用） | 作业题的参考解答 |

## 图注与插图规范

- **每图必讲**：讲义里出现的每张图都要有配文——图注交代读法，正文至少一段文字讲解它承载的知识点，并用 `\ref` 引用；只贴图不讲解视为未完成收录。
- **缩放意识（硬规则）**：每张 `\includegraphics` 必须显式给宽度，按信息密度缩放——350 dpi 高清抠图缩小不会糊，放心缩。**禁止不缩放直接塞入，导致一整页只有一张图、没有文字**；电路图等原理图适当缩小后完全可读。分档参考：
  - 小图（单个符号、简单小电路、图标）：0.3–0.5\linewidth，优先 `wrapfig` 环绕或 minipage 并排，别浪费横排空间；
  - 中图（结构图、流程图、单张电路图）：0.5–0.75\linewidth；
  - 大图（多子图、密集标注的复杂图表）：0.85–\linewidth；
  - 仅当原图极复杂、缩小后不可读时才允许接近满页，且同页或次页必须紧跟讲解文字。
- 图注小字、自动编号"图 N"，内容是**解释这张图讲什么原理、怎么读**，并注明课件页码（如"课件第 8 页原图"），不是复述画面元素。
- 相关联的图（结构详图 + 简化符号、错误做法 + 正确做法对比）用 `minipage` 并排，各设合适宽度；双栏并排时优先 `[htbp]` + minipage，避免 figure 环境互相挤位。

## 版式选择：单栏 / 双栏 / 文字环绕

三种版式可整册选用，也可在同一册内混搭（实现片段见 `references/latex-template.md`）：

| 版式 | 适用场景 | 实现 |
|---|---|---|
| 单栏（默认） | 公式多、宽表多、图大——最稳妥 | 现有模板即单栏 |
| 双栏 | 文字密集、图表小而多、想省纸 | 局部用 `multicols` 环境；整册在目录后 `\twocolumn` 切换 |
| 文字环绕 | 宽度 ≤ 半栏的小图配长段文字，穿插打破"图占一整行"的单调 | `wrapfigure` 环境 |

- 默认单栏。用户点名要双栏/紧凑排版，或某几节明显是"小图 + 长文字"时才启用对应版式；不为花哨牺牲公式与表格的稳定性。
- 宽元素禁忌：内容地图表（`\begin{tabularx}{\textwidth}`）、longtable 名词表、跨栏大图进双栏会挤爆栏宽——局部双栏不要把它们包进 `multicols`；整册双栏用 `figure*`/`table*` 跨栏放。
- `wrapfigure` 三条纪律：环境放在要环绕的段落之前、宽度 ≤ 0.5\textwidth、别紧贴章节标题或放在页面最后几行（原因与写法见模板片段）。

## 输出语言

讲义正文、图注、表格全部中文，专有名词保留英文并在首次出现时给中文译名（名词对照表兜底）；tex 注释可用中文。
